# Prompt cookbook

Human-maintained prompt examples.

This file is not part of the agent instruction routing and should not be treated as repository policy. Do not read or apply this file unless the user explicitly asks for prompt examples.


```
the goal of today is <...>.
read the relevant docs, make a plan for how you intend to proceed, divide the work in coherent and appropriately sized units, handoff. do not start yet
```

```
workflow: implement one unit per turn, handoff, and give me the chance to review and commit the changes before starting the next. if the change is too big, it may be broken down into small sized commits. let's keep a two-turns round: first change, second commit. unless different instructions, you should assess how to divide the commits and choose the messages; i will explicitly approve staging or committing.
let's start
```
