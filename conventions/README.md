# Project conventions

These are action-specific instructions for working in this repository. Read
this index first, then read the convention file for every category touched by
the task before editing anything.

| Action | Required convention |
| --- | --- |
| Editing C++, headers, or tests | [Code](code.md) |
| Changing CMake, build, or test configuration | [Build and test](build.md) |
| Editing Markdown or LaTeX | [Documentation](documentation.md) |
| Creating commits or changing branches/remotes | [Git](git.md) |

If a task spans multiple categories, read all corresponding files. These files
describe working practices and repository boundaries; the design authority for
the mathematical and semantic model remains in [`docs/`](../docs/README.md).
