# Planning reviews

This directory contains review evidence and remediation handoffs for work
already performed. The [implementation roadmap](../implementation-roadmap.md)
remains the sole owner of mutable feature status, acceptance state, and the
current handoff.

- [Pre-Chapter 5/6 review](pre-ch5-ch6/README.md) records the bounded
  readiness assessment and its Stage B execution plan.
- [Chapter 5 reviews](chapter-5/README.md) record the C1/C2 preparation and
  selected Chapter 5 implementation remediation reviews.
- [Chapter 6 reviews](chapter-6/README.md) record the incremental P6
  implementation review and remediation handoffs.
